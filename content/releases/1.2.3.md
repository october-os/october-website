## ISO

Updated the october installer to version [v1.2.3](https://github.com/october-os/october-installer/releases/tag/v1.2.3).

We also removed the `installer` directory in the root home directory. It is used in dev, but leaving it empty in releases
could cause confusion.

### What's Changed
* Remove installer folder in release in [pull request 14](https://github.com/october-os/october-iso/pull/14)

[Full Changelog](https://github.com/october-os/october-iso/compare/1.2.2...1.2.3)

## Installer

New tests were added to test the `grub` package. This brings us to around 69% unit tests coverage for the installer's features.
Also, a bug where user extra packages weren't installed was fixed in this release.

### What's Changed
* fixed bug by moving code block to the right place in [pull request 105](https://github.com/october-os/october-installer/pull/105)
* tests written for grub package in [pull request 101](https://github.com/october-os/october-installer/pull/101)

[Full Changelog](https://github.com/october-os/october-installer/compare/v1.2.2...v1.2.3)
